# Evaluation Skill

## Goal
Measure whether the compliance system is reliable enough for its intended use.

## Method
1. Establish a baseline.
2. Run the proposed change.
3. Compare against the same golden dataset.
4. Inspect regressions and newly exposed failure modes.
5. Measure classification, grounding, evidence, consistency, and security.
6. Review representative outputs manually.
7. Record evaluation results with model/prompt/legal/retrieval versions.
8. Promote only when quality and operational thresholds are satisfied.

Include obvious, borderline, incomplete, contradictory, exception, and adversarial cases.
