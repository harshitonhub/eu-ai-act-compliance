# Adversarial Testing Skill

Test:
- Misleading system descriptions
- Contradictory evidence
- Missing critical facts
- Prompt injection in uploaded documents
- Malicious retrieved content
- Outdated legal sources
- Forced YES/NO classification
- Conflicting actor roles
- Edge cases around exceptions
- Attempts to make the model ignore provenance

For each failure, record:
scenario → expected behavior → actual behavior → severity → root cause → remediation → regression test.
