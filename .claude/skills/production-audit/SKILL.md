# Production Audit Skill

Audit the system across:
- Architecture
- Security
- Legal knowledge
- AI/LLM behavior
- Evaluation
- Data governance
- Observability
- Reliability
- Reproducibility
- Documentation
- Operational readiness

For every finding record:
area → severity → evidence → risk → recommendation → owner/next action.

Final status:
PASS / CONDITIONAL_PASS / FAIL.
