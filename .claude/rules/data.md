# Data Rules

- Legal knowledge must be versioned.
- Preserve source documents, provisions, requirements, applicability metadata, exceptions, effective dates, and provenance separately.
- Use stable requirement identifiers.
- Store assessment facts separately from conclusions.
- Preserve evidence provenance and document metadata.
- Make temporal validity explicit.
- Use migrations for schema changes.
- Apply data minimization and retention policies.
- Design storage for tenant isolation and auditability.
